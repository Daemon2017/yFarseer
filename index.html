О проекте yFarseer

yFarseer — это бесплатный биоинформатический онлайн-инструмент, разработанный для точного предсказания субкладов Y-SNP на основе гаплотипов Y-STR.

В основе сервиса лежит глубокая нейросеть (двухслойный MLP с эмбеддингами маркеров на PyTorch), обученная с применением иерархического скоринга и кастомной функции потерь MaskedBCELoss. Модель учитывает филогенетическое дерево мутаций и оценивает топологию с заданным уровнем доверия (Confidence).

Основные возможности:

  • Поддержка до 111 стандартных маркеров Y-STR (от DYS393 до DYS435).
  • Полная совместимость с популярными панелями: FTDNA (Y12, Y25, Y37, Y67, Y111, BigY-500, BigY-700), Yfiler (Y17/Y27), PowerPlex (Y23), Генопоиск (Y50/Y67) и другими стандартными форматами тестов.
  • Автоматический парсинг сырых данных (Raw haplotype data) из форматов CSV, TSV или обычного скопированного текста.
  • Разделение маркеров по стандартным панелям (Panel 1–5), включая мультикопийные маркеры (DYS385, DYS459, YCAII, CDY, DYF395S1, DYS413, DYS464).
  • Построение интерактивной цепочки иерархической топологии субкладов.

About yFarseer

yFarseer is a free bioinformatics web tool designed for accurate Y-SNP subclade prediction from Y-STR markers.

Powered by a deep neural network (PyTorch MLP with marker embeddings), the predictor utilizes a custom hierarchical MaskedBCELoss that accounts for the phylogenetic mutation tree structure, estimating subclade topology at various confidence levels.

Key Features:

  • Supports up to 111 standard Y-STR markers (from DYS393 to DYS435).
  • Broad compatibility with commercial & forensic panels: FTDNA (Y12, Y25, Y37, Y67, Y111, BigY-500, BigY-700), Yfiler (Y17/Y27), PowerPlex (Y23), Genopoisk (Y50/Y67), and more.
  • Parses raw haplotype text data (CSV, TSV, or space-separated tokens).
  • Handles multi-copy markers (DYS385, DYS459, YCAII, CDY, DYF395S1, DYS413, DYS464) grouped by panels 1 to 5.
  • Generates an interactive, step-by-step downstream Y-SNP haplogroup chain.
